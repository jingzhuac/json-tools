# ⚙️ JSON 工具台 (JSON Toolbox)

本地隐私优先的 JSON 校验/格式化小工具 —— **纯前端 · 单文件 · 无依赖 · 数据不上传任何服务器**。

![零上传](https://img.shields.io/badge/privacy-local--only-brightgreen)

## 功能
- ✅ **校验并美化**（缩进 4/2 可选）
- ✅ **压缩成一行**
- ✅ **美化 + 按键排序**（对象键升序，嵌套/数组内也排）
- ✅ **转成单行转义串**（`\"` / `\\n`，方便塞进代码字符串）
- ✅ **错误提示到具体行/列**（不再是含糊的 "Unexpected token"）
- ✅ 载入 `.json` 文件 / 插入示例 / 一键复制 / 结果放回输入

## 为什么值得用
- 🔒 **全程本机浏览器运行，数据绝不上传** —— 配置/接口响应/含敏感字段的 JSON 敢交给它。
- 🚫 **无需安装、不注册、不收费**，打开网页即用，也无所谓网络干不干净。

## 快速使用
浏览器直接打开 `index.html`，或本地起个静态服务：

```bash
python3 -m http.server 8138   # 或 npx serve .
```

## 技术说明
- 基于浏览器原生 `JSON.parse`（正确性有保障），外加自研的友好错误行列定位与递归按键排序。
- 单测（node）：合法解析 / 错误定位到第 3 行 / 顶层·嵌套·数组内按键排序 / 中文往返 —— 全 PASS。
